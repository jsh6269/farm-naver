# 쥬니어네이버 동물농장

Convert pure HTML to JSX

## 구현 내역

- 은행(`/bank`) 페이지를 추가하여 물품 보관소, 마을정보, 예금하기, 출금하기 버튼이 있는 은행 화면을 보여준다.
- 여행사(`/travel`) 페이지를 추가하여 여행지 상품 목록과 떠나기 버튼, 내 동물 찾기 버튼이 있는 여행 화면을 보여준다.
- 마법 미용실(`/beautyshop`) 페이지를 추가하여 동물 선택, 물감 선택, 변신하기로 이어지는 3단계 미용 화면을 보여준다.
- 기부하기(`/donation`) 페이지를 추가하여 기부 안내와 빈 기부 목록, 아이템 가게로 가는 버튼을 보여준다.
- 아르바이트(`/work`) 페이지를 추가하여 마을 가게에서 일할 수 있는 여러 아르바이트 직업을 아이콘 목록으로 보여준다.
- 성주의 집(`/castle`) 페이지를 추가하여 성 내부 장면과 마을 예산 소식·회의장·성주의 방·작물 재배·아이템 받기 버튼을 보여준다.
