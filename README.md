# 쥬니어네이버 동물농장

Convert pure HTML to JSX

## 구현 내역

- 은행(`/bank`) 페이지를 추가하여 물품 보관소, 마을정보, 예금하기, 출금하기 버튼이 있는 은행 화면을 보여준다.
- 여행사(`/travel`) 페이지를 추가하여 여행지 상품 목록과 떠나기 버튼, 내 동물 찾기 버튼이 있는 여행 화면을 보여준다.
- 마법 미용실(`/beautyshop`) 페이지를 추가하여 동물 선택, 물감 선택, 변신하기로 이어지는 3단계 미용 화면을 보여준다.
- 기부하기(`/donation`) 페이지를 추가하여 기부 안내와 빈 기부 목록, 아이템 가게로 가는 버튼을 보여준다.
- 아르바이트(`/work`) 페이지를 추가하여 마을 가게에서 일할 수 있는 여러 아르바이트 직업을 아이콘 목록으로 보여준다.
- 성주의 집(`/castle`) 페이지를 추가하여 성 내부 장면과 마을 예산 소식·회의장·성주의 방·작물 재배·아이템 받기 버튼을 보여준다.
- 와글와글 장터(`/sale`)의 매물을 web.archive.org 스냅샷에서 추출한 실제 데이터 163건(아이템명·설명·가격·아이디·종료시간)으로 채우고, 아이템 도감과 이름을 매칭해 실제 썸네일 이미지를 표시하며 한 페이지 8개씩 10페이지 단위로 페이지네이션한다.
- 와글와글 장터(`/sale`)에 아이템 이름/아이디 기준 검색 기능을 추가하고, 목록에서 잘려 보이는 설명은 상세 모달에서 한 문장으로 완성된 전체 설명을 보여준다.
- 동물가게 스토리(`/petshop/story`) 페이지를 원본 디자인대로 재현하여 서브타이틀·하단 띠 이미지와 함께 '크라라의 마법소동' 원본 플래시(main_story.swf)를 Ruffle 에뮬레이터로 재생한다.
- 동물 분양(`/petshop/shop`) 페이지를 원본대로 재현하여 한 화면에 동물 한 마리의 3단계 성장 모습과 표정·색상 선택 UI, 분양받기 버튼(로그인 필요)을 보여주고 이전/다음으로 27종을 넘겨보며, 동물마다 고유한 색상 스와치(예: 수달 pink/green/blue)를 표시한다.
- 분양 페이지의 성장·표정·색상 조합 이미지 중 로컬에 없던 477개를 Wayback Machine 스냅샷에서 받아 채워, 스와치를 누르면 실제 색상으로 미리보기가 바뀌도록 했다.
- 동물 입양(`/petshop/adopt`) 페이지를 원본대로 재현하여 말풍선 게시판에 입양 동물 14마리(한마디·동물·이름)를 보여주고, 동물을 누르면 능력치 막대(애정·매력·건강·지식지수)와 이름·성별·특징, 입양하기 버튼이 있는 상세 화면으로 전환한다.
- 동물가게(`/petshop`) 메인의 새로운 동물·동물 입양·동물 미용실 배너를 각각 분양·입양·미용실 페이지로 이동하도록 연결한다.
- 동물가게(`/petshop`) 메인의 '새로운 동물 성장법'·'마법카드 설명보기' 버튼을 누르면 원본 팝업을 재현한 모달로 성장 단계 안내와 마법카드 7종 설명을 보여준다.
- 포인트 게임(`/pointshop`) 초급·중급·고급(`/pointshop/level/1~3`) 목록 페이지를 원본 디자인대로 구현하고, 보유한 플래시를 Ruffle로 실행하는 게임 플레이 페이지(`/pointshop/play/:id/:level`)를 연결한다(꽃 바구니·눈 몬스터·퀴즈 대결·크라라와 이상한 방 중급 등 추가 SWF 포함).
